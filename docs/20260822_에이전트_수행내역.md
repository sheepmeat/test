## Q2 — gap / freeze / flat / stale → INPUT_UNAVAILABLE contract

### Scope

Q2는 Q1 타이밍 증거를 상속해, 생리 추론을 거부해야 하는 입력 품질 계약을 동결한다. 모델을 학습하지 않고, R1을 구현하지 않으며, Q3 NORMAL→APNEA 오탐 평가를 하지 않는다.

### Git isolation

Q1 PR #115가 미병합이므로 Q2는 `b643bbfa48c07897406fa168f959b2037ad9adae`에서 스택했다. 베이스는 `feature/mmwave-v2-q1-synthetic-timing-corruption`. D1/D2/R1 미병합 조상은 없다.

### Q1 inheritance

수신 100 ms, source-update `ts_monotonic_ms - phase_age_ms`, 8 ms 재발행 가드, core 재발행 run 최대 1, exact transport duplicate 0. Q1 `CADENCE_JITTER` / 단독 `SOURCE_REPUBLICATION`은 계속 사용 가능 입력이다.

### Gap definition

M-N4 상속: 후보 창의 허용 source-update 간격이 `max(400 ms, 4 × window median)`을 넘으면 `LARGE_GAP`. 보간 금지. 합성 예시는 로드맵 0.5 s.

### Freeze definition

source-update가 8 ms 이상 전진하지 않은 채 receive 시각이 400 ms 이상 흐르면 `SOURCE_FREEZE`. `breath_phase` 등호만으로 정의하지 않는다. 3598-run은 검증 증거이지 임계값이 아니다.

### Stale definition

`phase_age_ms >= 400`. 새 `seq`는 stale source를 신선하게 만들지 않는다. 공개 native에 freshness가 없으면 해당 검출은 적용하지 않고, production MR60에서 freshness 부재는 사용 불가다.

### Flat definition

정확한 상수/비유한/unique==1, 또는 source가 전진하는 동안 400 ms 이상 완전 동일 구간. near-flat MAD 컷은 동결하지 않는다.

### Low-amplitude distinction

작은 진폭이지만 동적으로 변하는 트레이스는 `PHYSIOLOGY_ELIGIBLE`이다. V1 MAD 증폭 문제를 진폭 컷으로 뒤집지 않는다.

### Presence precedence

`human_detected_raw` false/unknown → `PRESENCE_SUPPRESSED`. presence true + 품질 실패 → `INPUT_UNAVAILABLE`. presence true + 품질 통과 → `PHYSIOLOGY_ELIGIBLE`. no-person ≠ APNEA.

### Synthetic quality profile

`MMWAVE_V2_Q2_INPUT_UNAVAILABLE_CORRUPTION_PROFILE_V1`. 무효 타깃은 `INPUT_UNAVAILABLE`. 생리 라벨을 다시 쓰지 않는다.

### Validation

`tests/test_mmwave_q2_input_unavailable.py` 11 passed. Q1 typical jitter와 단독 재발행은 유효. Q1 handoff 3598/2884/158380 ms/42637 ms/timestamp collision은 사용 불가.

### Limitations

near-flat 임계, 모델 준비 history 길이, Pi host timestamp residual은 미동결. 이 한계가 손상 입력을 APNEA로 통과시키지는 않는다.

### Q3 / M-PV1 handoff boundary

Q3는 이 계약 위에서 NORMAL→고신뢰 APNEA 오탐 게이트를 다룬다. M-PV1은 R1 표현과 품질 헤드 아키텍처를 결합한다. Q2는 그 아키텍처를 선택하지 않는다.

## 5. Native D1 어댑터

구현 파일: `adapters/mmwave_d1_2417ghz_adapter.py`

### 입력 및 채널 해석

- 기본 입력: payload의 명시적 `radar_I`, `radar_Q`
- Six-Port raw detector 입력이 명시적으로 제공되는 경우에만 `I = B5 - B6`, `Q = B3 - B4` 사용
- 배열 순서로 채널 의미를 추론하지 않음
- 필수 채널 누락, 부분 B3–B6, malformed 배열, non-finite 값, 길이 불일치, 지원하지 않는 `Fs`는 fail closed

### 변환

1. source가 요구하는 full-recording ellipse correction을 결정론적으로 적용
2. corrected trajectory에서 `atan2(Q, I)` 계산
3. `np.unwrap`으로 `native_unwrapped_phase_rad` 생성
4. `relative_displacement_m = phase * wavelength / (2π)` 계산
5. absolute distance가 아닌 relative displacement로 표시

Ellipse 보정은 공개 논문의 처리 요구사항을 반영했지만, 공개 구현이 P-code이므로 byte-identical 구현이라고 주장하지 않는다. 수치 안정화를 위한 conditioning은 ellipse fitting 내부에서만 사용하며, recording/window를 unit amplitude로 정규화하지 않는다.

### 기준신호 및 provenance

각 adapted record은 다음을 보존한다.

- subject
- session/recording 및 `measurement_info`
- source file
- condition 및 source quality rating
- source sampling rate와 sample range
- radar hardware/domain
- native radar signal 통계
- `respiration` reference channel, units, sample alignment
- adapter profile 및 quality/provenance flags

공통 8 Hz/240 samples 변환, local MAD normalization, D0/MR60 scaler, derivative, spectrum, autocorrelation, breathing score, RR target encoding, temporal hold logic는 적용하지 않았다.
