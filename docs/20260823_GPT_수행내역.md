### Breathing evidence

D0의 authoritative A6 reference/RR audit와 voluntary non-breathing event timing을 사용했다. `BREATHING_REFERENCE_PRESENT`, `BREATHING_REFERENCE_ABSENT`, `BREATHING_REFERENCE_AMBIGUOUS`, `TARGET_UNAVAILABLE`을 명시적으로 분리했다. 레이더 amplitude, R2 feature score, RR category는 reference label이 아니다.

D0 TRAIN에는 162개 `PRESENT`, 156개 `AMBIGUOUS`가 있다. full-window hold가 실제 TRAIN compact window에 없으므로 `ABSENT`를 인위적으로 만들지 않았다. 이는 contract state가 없는 것이 아니라 관측된 TRAIN evidence의 한계다.

### RR

`rr_bpm`을 primary continuous target으로 유지했다. D0에서는 기존 A4 `MOVESENSE_CHEST_ACC` spectral-peak reference method와 0.1–0.7 Hz band를 상속했다.

- D0 RR target available: 162
- D0 RR target unavailable: 156 (hold/transition overlap)
- unavailable RR: `rr_bpm: null` + explicit reason
- `0 bpm` sentinel: 사용하지 않음
- MR60 `breath_rate_raw`: 사용하지 않음

### Temporal hold

event-relative fields는 onset/offset distance, hold elapsed time, baseline, recovery, transition state를 보존한다. D0 TRAIN의 156 event-overlap rows는 전체 window `APNEA`로 덮지 않고 다음 상태로 기록했다.

- `HOLD_ONSET_AND_RECOVERY_WITHIN_WINDOW`: 8
- `HOLD_ONSET_WITHOUT_RECOVERY_IN_WINDOW`: 123
- `HOLD_ACTIVE_AT_WINDOW_START_AND_RECOVERY`: 25
- `NO_HOLD_EVENT_IN_WINDOW`: 162

previous valid breathing baseline이 없는 시작 상태는 hold candidate로 승격하지 않는다. recovery가 관측되면 event를 종료하고 다음 recording/window로 상태를 넘겨 carry-over하지 않는다. 최종 persistence threshold는 `DEFERRED_TO_M_PV1`이다.
